# Global Specification

The **global** subsystem defines constants, shared types, and universal metadata used across PAN♾RAMic.os.

---

## Purpose

- provide global enums  
- define pillar names  
- define world constants  
- unify shared types across core and engine  

---

## Components

### Pillars
Defines the 12 pillars of civilization.

### Types
Shared interfaces for:
- world  
- population  
- environment  
- humanitarian  
- governance  

### Constants
Global thresholds and scaling values.

---

## Notes

This subsystem contains no logic — only definitions.
