# Leech construction implementation note

This module implements the explicit extended-Golay coordinate definition
described by Robert A. Wilson, *The Leech lattice* (QMUL seminar notes, 2008),
section 3. The lattice vectors are integral coordinate vectors divided by
sqrt(8), with common coordinate parity, a Golay residue condition, and the
coordinate-sum congruence modulo 8.

The extended binary Golay code is generated by extending the binary
[23,12,7] cyclic Golay code with generator polynomial
x^11+x^9+x^7+x^6+x^5+x+1. The implementation checks all 4096 words,
the [24,12,8] weight enumerator, and self-orthogonality (hence self-duality
from dimension 12).

It explicitly enumerates the three shortest-vector families:

- 1,104 vectors of shape (±4, ±4, 0^22);
- 97,152 vectors of shape (±2^8, 0^16), supported on Golay octads with
  an even number of minus signs;
- 98,304 vectors of shape (±3, ±1^23), with sign patterns from Golay words.

Every generated vector is checked against the defining congruences and has
integral squared norm 32, i.e. lattice squared norm 4 after division by sqrt(8).
The resulting 196,560-vector shell contains no norm-2 roots.

**Scope limitation:** this validates the Golay code and the explicit minimal
shell construction. It does not yet construct a 24x24 basis, independently
compute its Gram determinant, enumerate the entire lattice, or construct the
Leech lattice VOA / Monster action. Those remain separate milestones.
