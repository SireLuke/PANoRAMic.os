# State subsystem

The state layer establishes the initial planetary conditions used by PANoRAMic.os.

Key state parameters:
- population stability and dignity
- market stability, liquidity, and volatility
- ecological regeneration and risk
- infrastructure resilience and stress
- governance coordination and conflict indexes
- workforce stability and burnout
- PAR and resource caps derived from the runtime formulas

This layer operationalizes the initial world seed for all subsequent simulation and audit passes.
