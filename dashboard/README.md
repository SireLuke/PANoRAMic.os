# Dashboard subsystem

The dashboard layer renders the live planetary signal surface for PANoRAMic.os.

Primary dashboard parameters:
- tick: global simulation tick counter
- headline: current operational summary
- overallHealth: 0..1 systemic health index
- rams: RAMS score
- rsdv: scarcity vector
- parCap: PAR cap status
- dem: demurrage rate
- stag: stagnation index
- stability: global stability index
- scarcity: scarcity signal
- recovery: recovery signal

The visual system is designed to surface planetary health, system stress, and market conditions in a single operational surface.
