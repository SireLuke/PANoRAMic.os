# Dashboard Subsystem Specification

The dashboard subsystem presents:
- world state
- global signals
- RAMS audits
- synthesis coherence

Panels:
- World
- Economy
- Governance
- Humanitarian
- Harm
- Resources
- Population
- Synthesis

Inputs:
- WorldState
- GlobalSignals
- RamsTickReport

Outputs:
- DashboardState
- React panels for each subsystem
