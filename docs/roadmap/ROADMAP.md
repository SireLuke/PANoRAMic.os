PANoRAMic.os Roadmap

This roadmap outlines the major phases of PANoRAMic.os, from core architecture
to full multi-pillar deployment and PAR-based metabolism.

Phase 1 — Core Architecture

- Establish repo structure (api, app, cli, core, dashboard, engine, docs).
- Implement basic worldState and dashboard initialization.
- Add governance scoring (panitarian module).
- Define core design principles and motus operandi.

Status: In progress.

Phase 2 — Pillar Foundations

- Add ecological, cultural, rights, labor, commons, and market pillars.
- Define metrics for each pillar (carrying capacity, cultural diversity,
  rights protection, labor dignity, enclosure score, market integrity).
- Wire pillars into worldState and globalSignals.

Status: Planned.

Phase 3 — PAR Economy

- Define PAR as the core economic metabolism of the OS.
- Implement PAR supply, cap, and distribution logic.
- Add stewardshipFund (universal dignity baseline) and humanitarianPool.
- Integrate PAR with rights, labor, ecology, and commons metrics.
- Add PAR dashboards and CLI commands.

Status: Planned.

Phase 4 — RAMS Audits

- Implement RAMS (Risk, Accountability, Metrics, Stewardship) audit modules.
- Add audit coverage for ecology, culture, rights, labor, commons, markets,
  PAR economy, and inter-node coordination.
- Expose audit results in the dashboard and CLI.

Status: Planned.

Phase 5 — Cooperative Store

- Build a cooperative store panel showing ethical, cooperative, and union-made
  goods and services.
- Integrate PAR-based purchasing and certification signals.
- Display labor dignity, ecological impact, rights compliance, and commons
  openness for each item.

Status: Planned.

Phase 6 — Modes and Micro-AI

- Implement Light Mode for small devices with minimal datasets.
- Implement Full Planetary Mode with global datasets and full audits.
- Add a micro-AI layer for heavy retrieval, language nuance, and cultural
  context.
- Support cooperative knowledge meshes and future language scaffolding.

Status: Planned.

Phase 7 — Documentation and Community

- Expand docs with detailed specs for each pillar and subsystem.
- Add PAR specification, RAMS specification, and deployment guides.
- Invite contributions aligned with dignity, transparency, cooperation, and
  sustainability.

Status: Planned.
