## 1. The architecture in one paragraph

The **pan-fractal-kernel** is the foundation: the mathematical and geometric engine (E8 / Gosset 4₂₁ geometry, the V8 state framework, validation harnesses). **PANoRAMic.os** (Planetary Always-On Resource Allocation & Management Operating System) operates on top of that foundation as the broader coordination environment. **RelayWorks** (workforce & logistics) is, with PANoRAMic.os, one of the two *integrated systems*. **Everything else is modular and plug-and-play by design**, so institutions can use individual pieces — the stated goal is "to unsilo institutions, not get nickeled by one."

Canonical data path (kernel): **validated V8 input → Janus Hydra (UHFE/UDFE paired heads) → paired semantic record → eight-channel V8 projections → JOBF**.

**Pillar census (verified 2026-11-16): PANoRAMic.os has 39 pillars, not ~16** — Lucas's own count that evening was "16 pillars or so"; the `pillars/` tree in the current clone holds 39 directories (full list in §3). A directory existing is not proof of a working engine — depth per pillar is not yet audited, and at least one (quantum) is an explicit HOLD.

## 2. The V8 state — canonical coordinates

Order is fixed: **V8 = (h, R, u, d, tau, chi, s, f)**. All coordinates are normalised to [0, 1] **except chi, which is signed [−1, 1]** — chirality carries a sign. Canonical per the kernel; the PANoRAMic.os mirror had drifted to an affine [0, 1] squeeze that erased the sign and was realigned by PR #89 (2026-11-17).

| Symbol | Name | Meaning |
|---|---|---|
| h | coherence | how well the state hangs together |
| R | recursion | self-reference / recursive depth |
| u | construction | building-up processes |
| d | decoherence | dissolution / decoherence density |
| tau (τ) | temporal offset | time displacement — NOT "temporal persistence" |
| chi (χ) | chirality | handedness — **signed [−1, 1]**; a flip is a sign change (all other coordinates [0, 1]) |
| s | information density | information content per unit |
| f | forcing | external drive |

- Provisional input alias: `T` maps to `tau`. Persistence is NOT tau.
- Poster drift to ignore: "tau = Temporal Persistence" and "u = Constructive Polarity" are outdated poster labels.
